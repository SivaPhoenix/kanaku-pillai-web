# Architecture decisions

One file per decision: `ADR-NNNN-short-title.md` (for example `ADR-0001-auth-on-own-backend.md`). Write one when a choice is hard to reverse or would surprise a new contributor: libraries, data shapes, security trade-offs, or deviations from `docs/design-spec.md`.

```markdown
# ADR-NNNN: Title

- Date: YYYY-MM-DD
- Status: Proposed | Accepted | Superseded by ADR-NNNN

## Context
What forced the decision.

## Decision
What we chose.

## Consequences
What gets easier, what gets harder, what we must now do.
```

Decisions already taken at project start are listed in `docs/PROJECT.md` §5.
